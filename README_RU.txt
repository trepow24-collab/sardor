SARDOR CLEAN — сайт + Telegram-бот (Bothost)

СОСТАВ:
- main.py — FastAPI-сайт/API + Telegram-бот на aiogram 3
- index.html — исходный дизайн сайта, снежок и форма заявки
- requirements.txt — зависимости
- .env.example — пример переменных (сам файл .env.example не заполнять токеном)

ПЕРЕД ЗАПУСКОМ:
1. В Bothost создайте Python-проект из загруженного ZIP/репозитория.
2. Главный файл запуска: main.py
3. Порт приложения: 8000 (или тот, который Bothost передаёт через PORT).
4. В переменные окружения Bothost добавьте:
   BOT_TOKEN = ваш текущий токен (не публикуйте его и не присылайте в чат)
   OWNER_ID = 1967721013
   DEVELOPER_ID = 8799714877
   SITE_URL = адрес сайта после подключения домена, например https://example.bothost.ru
   PORT = 8000 (если панель требует указать вручную; значение должно совпадать с портом приложения)
5. Включите веб-интерфейс/домен и HTTPS, если эта настройка доступна для проекта.
6. Запустите деплой. Откройте домен — должен появиться сайт.
7. Откройте своего Telegram-бота и нажмите Start от аккаунта владельца и разработчика. Иначе Telegram не разрешит боту первым написать вам.

КАК РАБОТАЕТ:
- Форма на сайте отправляет POST /api/requests.
- Заявка сохраняется в SQLite в постоянной папке /app/data и отправляется владельцу и разработчику в Telegram.
- /start у владельца и разработчика показывает панель управления.
- В панели доступны заявки, статистика, отметка заявки как обработанной.

ВАЖНО:
- Не вставляйте BOT_TOKEN в index.html и не коммитьте его в Git.
- Если токен когда-либо попадал в публичную переписку/репозиторий, правильнее перевыпустить его в BotFather. Если оставляете прежний — храните только в закрытых переменных Bothost.
- Сайт и бот работают одним Python-процессом. Не запускайте отдельно второй экземпляр бота с тем же токеном (будет конфликт polling).\n\nОБНОВЛЕНИЕ ОФОРМЛЕНИЯ БОТА:\n- Эмодзи убраны из сообщений и кнопок панели.\n- Тексты сообщений панели и уведомлений выделены жирным.\n- Текст на кнопках Telegram нельзя сделать жирным: Telegram не поддерживает форматирование подписей кнопок.
